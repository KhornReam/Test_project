# FluentPath

A responsive, browser-native English learning platform demo built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` directly in a modern browser, or serve the folder with VS Code Live Server. No build step or backend is required.

## Included

- Hash-based SPA routes for Home, Courses, Practice, Progress, History, and Profile
- Onboarding with level selection and simulated demo authentication
- Course search, filters, enrollment, course details, and lesson completion
- Listening, grammar, speaking, and vocabulary practice flows
- Quiz scoring, feedback, browser speech synthesis, XP, streaks, achievements, notifications, and leaderboard sample data
- LocalStorage persistence for profile, route data, progress, saved words, and activity history
- Responsive desktop sidebar and mobile bottom navigation

OAuth, speech analysis, and certificates are represented as clearly labelled demo behavior and do not connect to real services.
